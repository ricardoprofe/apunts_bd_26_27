Unitat 3.2. Creació de bases de dades

1. El llenguatge SQL

SQL (Structured Query Language o Llenguatge de consulta estructurat) és un llenguatge estàndard de comunicació amb bases de dades relacionals. La principal característica d'aquest llenguatge és la seua simplicitat, ja que amb pocs coneixements es poden fer consultes bàsiques sobre una base de dades

El llenguatge SQL es pot dividir en tres conjunts d'instruccions o sentències segons la seva funció:

  • Les sentències de definició (DDL Data Definition Language) permeten crear, modificar i esborrar estructures de dades, com taules, vistes i índexs.
  • Les sentències de manipulació (DML Data Manipulation Language) permeten llegir, inserir, modificar i esborrar registres.
  • Les sentències de control (DCL Data Control Language) permeten finalitzar o rebutjar transaccions, crear usuaris i autoritzar o revocar els permisos dels usuaris.

El SQL permet dos modes d'ús:

  • Un ús interactiu, destinat principalment als usuaris finals avançats o ocasionals, en el que les diverses sentències SQL s'escriuen i s'executen a la línia d'ordres, o un entorn semblant.
  • Un ús integrat, destinat a l'ús per part dels programadors dins de programes escrits en qualsevol llenguatge de programació amfitrió. En aquest cas SQL agafa el paper de subllenguatge de dades.

2. El DDL de MySQL

El Llenguatge de Definició de Dades (DDL) de SQL permet definir els objectes de les nostres bases de dades. Amb ell podrem crear bases de dades, taules, claus, etc, així com crear vistes parcials de les taules i gestionar els diferents permisos per a cada usuari o grup d’usuaris, etc.

El DDL varia un poc d’un SGBD a altre (tipus de dades, etc). Nosaltres ens basarem en el MySQL.

2.1 Operacions bàsiques amb MySQL

Per a crar bases de dades i administra-les, accedim amb l'usuari asministrador:

1
mysql -h ip_del_server -u admin -p

o, en Ubuntu:

1
sudo mysql

Per a veure les BD que tenim, fem:

1
SHOW DATABASES;

Veurem una llista de les bases de dades que tenim. De moment tindrem només les que vénen per defecte amb MySQL:

Aquestes bases de dades són les que utilitza MySQL per a funcionar correctament. No hem de tocar-les, ja que si les modifiquem podem fer que el SGBD no funcione correctament.

  • information_schema: és una base de dades virtual que conté informació sobre totes les altres bases de dades que té el SGBD. Conté informació sobre les taules, vistes, columnes, etc.
  • mysql: és la base de dades que utilitza MySQL per a emmagatzemar la informació sobre els usuaris, permisos, etc.
  • performance_schema: és una base de dades virtual que conté informació sobre el rendiment del SGBD.
  • sys: és una base de dades virtual que conté informació sobre el rendiment del SGBD i sobre les consultes que s'han executat.

Instruccions bàsiques per a treballar amb bases de dades

  • Per a treballar amb una base de dades (que ja estiga creada):
1
USE nom_base_de_dades;
  • Per a consultar amb quina base de dades estem treballant:
1
SELECT database();
  • Per a vuere les taules que té una base de dades:
1
SHOW TABLES;

Exemple:

1
2
3
4
SHOW DATABASES;
USE mysql;
SELECT database();
SHOW TABLES;

MySQL és case-insensitive per a les instruccions, és a dir, no fa diferència entre majúscules i minúscules. Però els noms de les taules i columnes sí són case-sensitive.

Per exemple, les instruccions següents són equivalents:

1
2
3
SHOW DATABASES;
show databases;
Show Databases;

Però les següents instruccions no són equivalents:

1
2
3
USE mysql;
USE MySQL;
USE MYSQL;

Per tant, les instruccions SQL es poden escriure en majúscules o minúscules. No obstant això, és una bona pràctica escriure les instruccions SQL en majúscules i els noms de les taules i columnes en minúscules.

Operacions amb bases de dades

Per a crear una base de dades, fem:

1
CREATE DATABASE nom_base_de_dades;

Per a eliminar una base de dades, fem:

1
DROP DATABASE nom_base_de_dades;

MySQL Data Types

Tipus numèrics

Els tipus numèrics es poden classificar en enters i decimals. Els enters són números sense decimals, mentre que els decimals són números amb decimals.

Per als enters, podem utilitzar els tipus TINYINT, SMALLINT, MEDIUMINT, INT i BIGINT. Aquests tipus de dades tenen diferents rangs de valors que poden emmagatzemar.

Els enters poden ser UNSIGNED, és a dir, només poden emmagatzemar valors positius. Per exemple, un TINYINT UNSIGNED pot emmagatzemar valors entre 0 i 255. Per defecte, els enters són SIGNED, és a dir, poden emmagatzemar valors positius i negatius.

Per a valors monetaris en els quals és important la precisió, és millor utilitzar el tipus DECIMAL(m, d), on m és el nombre total de dígits i d és el nombre de dígits després del punt decimal. Per exemple, DECIMAL(10, 2) pot emmagatzemar números amb fins a 10 dígits en total, dels quals 2 són decimals.

El tipus BOOL o BOOLEAN és un tipus especial que només pot emmagatzemar els valors TRUE (1) o FALSE (0).

Tipus de text

  • CHAR(n) ocupa sempre n caràcters, encara que no s'utilitzen tots. Per exemple, si definim una columna com CHAR(10) i inserim la paraula "hola", MySQL emmagatzemarà "hola " (amb 6 espais en blanc al final).
  • VARCHAR(n) ocupa només els caràcters que s'utilitzen. Per exemple, si definim una columna com VARCHAR(10) i inserim la paraula "hola", MySQL emmagatzemarà només "hola" (sense espais en blanc al final).
    CHAR i VARCHAR

Utilitzarem CHAR quan sapiguem que totes les dades tindran la mateixa longitud, com per exemple un codi postal. En canvi, utilitzarem VARCHAR quan les dades poden tenir longitud variable, com per exemple un nom o una adreça.

El tipus TEXT s'utilitza per a emmagatzemar grans quantitats de text, com per exemple un article o un comentari. Aquest tipus de dades pot emmagatzemar fins a 65.000 caràcters.

Tipus de data i hora

  • DATE guarda dates en el format any-mes-dia ('0000-00-00').
  • TIME guarda les hores en el format hora:minuts:segons ('00:00:00'). Amb la funció DATE_FORMAT() es pot mostrar en format AM i PM.
  • DATETIME o TIMESTAMP guarden la data i l'hora en el format any-mes-dia hora:minuts:segons ('0000-00-00 00:00:00').
  • YEAR guarda l'any en 4 dígits.

DATETIME i TIMESTAMP són molt similars, però hi ha algunes diferències importants. DATETIME mostra els valors en format 'YYYY-MM-DD HH:MM:SS'. TIMESTAMP emmagatzema els valors com un nombre enter que representa el nombre de segons des del 1 de gener de 1970 (epoch).

El tipus BLOB

Un BLOB (Binary Large Object) és un tipus de dades que s'utilitza per a emmagatzemar grans quantitats d'informació binària, com ara imatges, sons o vídeos. Els BLOBs poden ser de diferents tipus segons la seua grandària:

  • TINYBLOB: fins a 255 bytes.
  • BLOB: fins a 65.535 bytes (64 KB).
  • MEDIUMBLOB: fins a 16.777.215 bytes (16 MB).
  • LONGBLOB: fins a 4.294.967.295 bytes (4 GB).
